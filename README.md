## 📖 About The Project

**MythForge** is an interactive fantasy character generator designed for tabletop RPG enthusiasts, fantasy writers, and role-playing game creators.

The application creates unique fantasy adventurers with personalized names, character classes, dynamic portraits, RPG attributes, and imaginative origin stories.

From legendary warriors to mysterious mages, MythForge provides an immersive environment where users can summon, explore, and collect their own fantasy heroes.

## ✨ Features

- ⚔️ **Procedural Character Generation:** Generate unique fantasy adventurers with randomized names, classes, and identities.
- 🎨 **Dynamic Character Portraits:** Generate and regenerate fantasy-style character artwork matching each hero's identity and class.
- 📜 **Generative Lore & Backstories:** Create imaginative origin stories and personalized character lore.
- 🛡️ **RPG Stat Cards:** Display important character attributes, including Health, Mana, and Strength.
- 🧙 **Multiple Character Classes:** Explore fantasy archetypes such as Mage, Rogue, Warrior, Cleric, and more.
- 📚 **Persistent Deck Collection:** Save summoned heroes to a personal collection for future reference.
- 🏰 **Thematic Workbench UI:** Experience an Ancient Alchemist's Workbench-inspired interface with dark parchment textures, antique elements, and fantasy typography.
- 🔊 **Procedural Audio Effects:** Interactive sound effects and magical chimes using the Web Audio API.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v20.19+ or v22.12+)
- npm
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/tanusreepittala/MythForge.git
```

### 2. Navigate to the Project Directory

```bash
cd MythForge
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the following address in your browser:

```text
http://localhost:3000
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

## 🎮 How It Works

1. **Summon:** Start the fantasy character generation process.
2. **Generate:** Create a unique fantasy adventurer with a name, class, attributes, and backstory.
3. **Visualize:** Generate a character portrait matching the hero's identity.
4. **Explore:** Discover character details, lore, and RPG statistics.
5. **Collect:** Save favorite heroes to your personal deck.
